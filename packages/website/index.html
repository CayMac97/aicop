How It Works

From zero to scanned in 30 seconds

No configuration required. Point it at your project and get actionable results instantly.

01

Install

One command. Works with npm, pnpm, or yarn. No configuration required to start scanning.

02

Scan

Parses your TypeScript and JavaScript into ASTs, then runs all 29 detection rules across every file.

03

Score

Every file gets a VibeScore™ (0–100). Know at a glance how AI-heavy your codebase is.

04

Fix

Each finding includes a plain-English explanation and a concrete fix suggestion. No jargon.

Install

Up and running in seconds

Install once globally, or use npx for a one-off scan with no installation needed.

Terminal
# Install globally once
npm install -g vibecop

# Scan your project
vibecop scan ./src

# Generate an HTML report
vibecop scan ./src --format html
Terminal
# Run without installing
npx vibecop scan ./src

# With HTML report
npx vibecop scan ./src --format html

# Scan only changed files
npx vibecop diff main
Terminal
pnpm dlx vibecop scan ./src

# Or as a dev dependency
pnpm add -D vibecop
.github/workflows/vibecop.yml
- name: VibeCop scan
run: npx vibecop scan ./src --ci --format json --output vibecop-report.json

# Exits with code 1 if errors are found — fails the build
New

Show your score
